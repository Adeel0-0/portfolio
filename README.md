# Adeel — Portfolio

Minimalist, futuristic portfolio built with **Next.js 14**, **Tailwind + shadcn-style components**, and **Three.js** (particle wave + wireframe icosahedron hero).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy (free)

Push to GitHub, then import the repo at [vercel.com](https://vercel.com) — zero config needed.

## Customize

- All content (name, projects, skills, links) lives in `data/resume.ts`.
- **TODO:** replace the placeholder `github` / `linkedin` URLs in `data/resume.ts` with your real profiles.
- Colors/theme: `app/globals.css` (change `--primary` HSL to re-accent the whole site).
